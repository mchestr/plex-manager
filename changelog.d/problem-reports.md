### Added

- **Report a problem:** members can report a problem with a title from the new `/report` page: find a title in their libraries, pick what's wrong, add a note, and follow the report's status. A title has one open report at a time; a second member can follow it or add a different problem. Every report goes to the server admin for now. The feature is off until it is turned on, and Help and the Home help card link to the page only while it is on. Members' reports are listed in Your data and removed with the member.
